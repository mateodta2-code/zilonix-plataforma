  **Qué guarda `resultado` para las publicaciones de prueba de Mateo, según el código** (sin llamar a ML): para una publicación clásica (sin variantes) con una sola cuenta, `resultado` es un array de un `ResultadoPublicacionExito` — `{cuentaMlId, ok:true, itemId, permalink: <lo que devolvió POST /items, probablemente http://...>, categoria, atributosAsumidos, status: "paused" si modoPrueba estaba activo (la pausa se intenta DESPUÉS de capturar permalink), modoPrueba:true/false, avisoFotosVariante, avisoMarca, avisoDescripcion}`.
