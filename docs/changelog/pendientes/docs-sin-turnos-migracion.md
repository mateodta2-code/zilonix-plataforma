- **2026-11-15** — Refs #36. Se quita la regla de turnos de migración. Desde el PR #419 el deploy de staging aplica solo las migraciones y `db/rls-setup.sql` (`scripts/migrar-al-desplegar.mjs`, ya configurado y verificado en Railway staging). Cualquiera puede mergear un PR con migración cuando el CI esté verde. Antes de mergear, actualiza la rama con `main`; si el número ya está ocupado o el CI marca números repetidos o un `when` fuera de orden, borra la migración y vuélvela a generar con drizzle-kit. Al mergear, revisa los logs (`[migrar-al-desplegar] Listo.`). Nunca un `COMMIT` dentro de una migración, y no borres ni renombres columnas que la versión anterior aún usa (dos pasos). Producción no cambia: las aplica a mano solo Mateo, en el release por la rama `produccion`. Sin cambio de código ni de CI.
