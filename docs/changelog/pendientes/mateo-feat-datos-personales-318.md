  **Hecho**
  - `lib/datos-personales.ts` (nuevo): `exportarDatosPropios` y `anonimizarCuentaPropia`. Ninguna de las dos recibe un id de usuario del cliente — siempre el de la sesión real (`obtenerOCrearUsuarioActual`), así que no hay forma de pedir el borrado/exportación de otra persona.

Las membresías de esa persona SÍ se borran (`DELETE` de `membresias`, una por empresa) — eso no choca con ningún `restrict`, nada referencia `membresias.id`.
