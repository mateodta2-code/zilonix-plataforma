- **Corrección: no existe una sincronización automática de ventas de respaldo.** Comentarios de `lib/ml/trabajador.ts` (y los fragmentos de #668 y #671) decían que una sincronización «de cada hora» (`lib/finanzas/traer-ventas-mes.ts`) cubría las ventas de los avisos que no se procesan. En realidad es el botón manual «Traer ventas de este mes» (Pedidos / Finanzas → Ventas) y solo trae el mes en curso. Se corrigen los comentarios y esos fragmentos; por eso un aviso de **venta** nunca se omite por viejo (#676 solo omite los que no son de venta).
- Guía del superadmin (Empresas → Reactivar, y Conexiones → qué hacer): tras reactivar o reconectar, pedirle al cliente que pulse «Traer ventas de este mes» para recuperar las ventas que no entraron.
