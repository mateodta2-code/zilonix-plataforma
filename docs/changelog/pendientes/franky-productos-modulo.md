- **2026-11-15** — Módulo **Productos** (pedido de Franky). SKU, Inventario y Bodegas dejan de ser tres ítems sueltos del menú lateral: ahora son un solo ítem, "Productos", que al tocarlo despliega debajo sus secciones (Inventario, SKU, Bodegas, Kardex, Ingresos, Compras y Configuración). La lista arranca abierta si ya estás en una de esas pantallas, con la sección actual marcada. Con la barra contraída o en pantalla angosta no hay lugar para la lista, así que el ítem lleva directo a Inventario. La barra de botones que tenían arriba las pantallas de inventario se quita. Las rutas no cambian (`/panel/sku`, `/panel/inventario/...`, `/panel/bodegas`) y los permisos tampoco (`inventario.consultar`). Las secciones viven en `components/productos/secciones.ts`: para sumar una nueva se agrega ahí una línea. `ItemNav` gana `hijos` para cualquier módulo desplegable. Sin migración.
