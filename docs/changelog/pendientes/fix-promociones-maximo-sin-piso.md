- Promociones: la regla «Máximo X %» ahora aplica SOLO el tope de % a cargo del vendedor — ya no exige precio mínimo cargado ni usa el piso de Finanzas (solo «Respetar la tabla maestra» lo hace). Si la promo pide más del X %, no participa y el motivo lo dice; «Descuento de precio» entra con el precio que deja X % si Mercado Libre lo permite. El servidor aplica el tope aunque la pantalla no lo haga, y la bitácora registra regla «Máximo X %» y límite «tope» también en la acción individual (Refs #605).
