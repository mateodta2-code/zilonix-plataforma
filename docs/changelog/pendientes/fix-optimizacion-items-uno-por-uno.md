- **fix-optimizacion-items-uno-por-uno** — **Optimización:** el detalle de una publicación decía «Mercado Libre no devolvió esa publicación. Puede que ya no exista» aunque existía. Mercado Libre respondió 403 a `/items?ids=` (el lote) mientras `/items/{id}` daba 200 para la misma publicación; se comprobó en staging el 19-nov con MCO1342632705 de STOREKINGSAS. Ahora `leerItemsOptimizacionMl` pide una por una las publicaciones que el lote no devolvió. Arregla también las publicaciones que le faltaban a la lista cuando un lote fallaba.
